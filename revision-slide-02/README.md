# Revisión de una sola lámina · Herramienta Mi Market

Esta prueba utiliza como base la imagen completa de la lámina 2 del PDF original. No reconstruye sus textos ni distribuye los elementos en una composición nueva.

La única intervención es la aparición acumulativa de las 11 herramientas en su posición original, una por clic. Ver completa muestra la imagen entera; Reiniciar vuelve al título. También funciona con las flechas del teclado.

Descarga el ZIP, descomprímelo y abre Slide-02-Herramientas.html. El GIF permite revisar el efecto automáticamente sin instalar nada.
